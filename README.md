# Banking Operations Analysis | Power BI

## Project Overview

This project focuses on analyzing banking operations using Microsoft Power BI. The main objective is to explore account performance, transaction activities, and branch operations to identify business trends and generate actionable insights.

The project uses a synthetic banking dataset to simulate real-world banking operations.

## Business Objectives

- Analyze account distribution and account performance.
- Monitor transaction activities and success rates.
- Evaluate branch-level operational performance.
- Identify trends and potential operational risks.
- Support data-driven business decisions.

## Dataset

The project includes three datasets:

- **Accounts:** Account types, account status, initial balances, and overdraft limits.
- **Transactions:** Transaction activities, transaction status, fees, and operational indicators.
- **Branches:** Branch locations, staff count, and monthly operating costs.

## Dashboard Pages

### 1. Account Analysis
- Account distribution by branch and account type.
- Average overdraft limits.
- Initial balance analysis.
- Account opening trends.

### 2. Transaction Analysis
- Transaction volume and activity.
- Successful, failed, pending, and reversed transactions.
- Transaction success rate.
- International and business-hours transaction analysis.

### 3. Branch Analysis
- Transaction volume by branch.
- Branch staff distribution.
- Monthly operating cost analysis.
- Branch-level operational performance.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV datasets

## Key Takeaways

The dashboard provides an overview of banking operations and helps identify patterns in account activity, transaction performance, and branch efficiency.
